# LinkedIn Project Entry

## Title
Oracle Reconciliation Engine

## Description
Designed an Oracle PL/SQL reconciliation engine for comparing transactional datasets and classifying business exceptions.

The engine handles matched records, missing transactions, amount/date/currency mismatches and duplicate detection, with configurable amount tolerance and full execution history for auditability.

Technologies: Oracle Database, SQL, PL/SQL, Reconciliation, Banking Data, Data Warehousing.
